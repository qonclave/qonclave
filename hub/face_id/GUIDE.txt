================================================================
  Qonclave Face Identification — Complete Setup & Run Guide
================================================================

----------------------------------------------------------------
ONE-TIME SETUP
----------------------------------------------------------------

1. Clone repo and install dependencies
   -----------------------------------
   git clone https://github.com/jogendar/Qonclave.git
   cd Qonclave\hub\face_id
   .\run.ps1


2. Add known faces
   ----------------
   Drop one clear front-facing photo per person into:
   hub/face_id/known_faces/

   File name = person's display name
   Examples:
     known_faces\mahesh_babu.jpg     (already included)
     known_faces\mahesh_babu2.jpg    (already included)
     known_faces\pawan_kalyan.jpg    (already included)
     known_faces\your_name.jpg       (add your own)

   Supported formats: .jpg .jpeg .png .webp
   One photo per person is enough. More photos = better accuracy.


3. (Optional) Setup NPU — Snapdragon X only
   ------------------------------------------
   Run once to export both AI models for Hexagon NPU:

   .\setup_npu.ps1

   What it does:
     - Prompts for your Qualcomm AI Hub token
       (Sign up free at: https://workbench.aihub.qualcomm.com
        Then: Account -> Settings -> API Token)
     - Exports MediaPipeFace + CavaFace via AI Hub cloud
     - Takes ~5-10 minutes
     - Saves models to hub/face_id/models/

   Skip this step if you only want CPU mode.


----------------------------------------------------------------
RUNNING
----------------------------------------------------------------

Windows (x86 or ARM64):

  Identify a person:
    .\run.ps1 identify  -Image unknown.jpg

  Compare two photos (same person?):
    .\run.ps1 compare   -Image1 photo1.jpg -Image2 photo2.jpg

  Benchmark speed:
    .\run.ps1 benchmark -Image photo.jpg

  NPU mode (Snapdragon X, after setup_npu.ps1):
    .\run.ps1 identify  -Image unknown.jpg -Npu
    .\run.ps1 benchmark -Image photo.jpg   -Npu


Linux / macOS:

  ./run.sh identify  unknown.jpg
  ./run.sh compare   photo1.jpg photo2.jpg
  ./run.sh benchmark photo.jpg
  ./run.sh --npu identify unknown.jpg


----------------------------------------------------------------
WHAT HAPPENS AT RUNTIME
----------------------------------------------------------------

.\run.ps1 identify -Image unknown.jpg [-Npu]
        |
        v
1. pip install deps
   (skipped if already installed)
        |
        v
2. Load models
   CPU mode:
     - MediaPipe .tflite  auto-downloaded 228KB on first run
     - CavaFace PyTorch weights  263MB cached at ~/.qaihm/
   NPU mode:
     - MediaPipeFace.onnx  loaded via QNNExecutionProvider (Hexagon NPU)
     - CavaFace.onnx + .data  loaded via QNNExecutionProvider (Hexagon NPU)
        |
        v
3. Load known face embeddings
   First run:
     - Detect + embed each image in known_faces/
     - Save to known_faces/.embeddings_cpu.npy (or _npu.npy)
   All subsequent runs:
     - Load .npy cache instantly (< 1ms)
     - Cache auto-rebuilds if you add/replace images
        |
        v
4. Process unknown.jpg
   - Detect face  ->  bounding box
   - Crop + resize  ->  112x112 pixels
   - CavaFace embed  ->  512-dimensional vector
        |
        v
5. Compare against known embeddings (cosine similarity)
   mahesh_babu    45.2%  <- best match
   mahesh_babu2   43.1%
   pawan_kalyan    5.8%
        |
        v
6. Output result
   Identified as: mahesh_babu (45.2%)
     -- or --
   Unknown person (best match only 12.3%)


----------------------------------------------------------------
SPEED SUMMARY
----------------------------------------------------------------

  Step                  CPU         NPU
  --------------------  ----------  ----------
  Load models           ~1s         ~1s
  Load DB embeddings    <1ms        <1ms  (cached)
  Detect face           ~15ms       ~0.7ms
  Embed face            ~250ms      ~4.3ms
  Match                 <1ms        <1ms
  --------------------  ----------  ----------
  Total per photo       ~265ms      ~6ms


----------------------------------------------------------------
SIMILARITY THRESHOLD
----------------------------------------------------------------

  Default: 30% (scores above 30% = same person)

  Tune in face_pipeline.py line:
    THRESHOLD = 0.3

  Lower  -> more permissive (fewer "Unknown" results)
  Higher -> more strict     (fewer false positives)


----------------------------------------------------------------
FILE LAYOUT
----------------------------------------------------------------

  hub/face_id/
    face_pipeline.py            core pipeline
    run.ps1                     Windows launcher (x86 + ARM64)
    run.sh                      Linux / macOS launcher
    setup_npu.ps1               one-time NPU model export
    constraints.txt             forces opencv-headless install
    face_detector.tflite        auto-downloaded on first run
    known_faces/
      mahesh_babu.jpg
      mahesh_babu2.jpg
      pawan_kalyan.jpg
      .embeddings_cpu.npy       auto-generated, do not commit
      .embeddings_npu.npy       auto-generated, do not commit
    models/                     populated by setup_npu.ps1
      CavaFace.onnx
      CavaFace.data             (~250MB weights)
      MediaPipeFace.onnx


----------------------------------------------------------------
TROUBLESHOOTING
----------------------------------------------------------------

  "No face detected"
    -> Use a clear, front-facing photo
    -> Ensure face is not too small in the frame

  "Unknown person" for a known person
    -> Lower threshold: THRESHOLD = 0.2 in face_pipeline.py
    -> Add more reference photos to known_faces/
    -> Delete .embeddings_*.npy to force cache rebuild

  Embeddings not updating after adding new photo
    -> Delete known_faces/.embeddings_cpu.npy
    -> Cache rebuilds automatically on next run

  NPU not activating
    -> Run setup_npu.ps1 first
    -> Verify models/CavaFace.onnx and models/MediaPipeFace.onnx exist
    -> Check QNN SDK is installed (QnnHtp.dll on PATH)

  opencv install fails on ARM64
    -> Run build_opencv_arm64.ps1 to build from source
    -> Then run run.ps1 normally
